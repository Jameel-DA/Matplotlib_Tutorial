# Matplotlib_Tutorial

📊 Cricket Data Analytics & Visualization
🏏 About the Project

This repository contains datasets and Jupyter notebooks focused on cricket data analysis and visualization using Matplotlib. The datasets include records of various batsmen, boundaries, and specific match performances, while the notebooks demonstrate different visualization techniques.

📂 Files & Datasets
Batsman Season Record (batsman_season_record.csv) – Performance of batsmen across different seasons.

Batter Data (batter.csv) – Statistical records of batters.

Big Array (big-array.npy) – Large numerical data array (specifics TBD).

Fours & Sixes (fours-sixes.csv) – Analysis of boundaries hit by players.

Chris Gayle's 175 (gayle-175.csv) – Detailed statistics of Chris Gayle’s record-breaking 175-run innings.

Sharma & Kohli (sharma-kohli.csv) – Performance comparison of Rohit Sharma and Virat Kohli.

Virat Kohli Stats (vk.csv) – Performance statistics of Virat Kohli.

Jupyter Notebooks:
Matplotlib Basics (Matplotlib_Basics.ipynb) – Introduction to Matplotlib for visualization.

Matplotlib Practice (Matplotlib practice.ipynb) – Hands-on examples and exercises.

Matplotlib Advanced (Matplotlib_Advanced.ipynb) – Advanced visualization techniques.

📊 Features
✔ Data preprocessing and cleaning

✔ Statistical analysis of batting performance

✔ Comparison of legendary cricketers

✔ Visualizing runs, boundaries, and trends using Matplotlib
